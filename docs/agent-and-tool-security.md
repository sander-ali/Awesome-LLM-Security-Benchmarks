> 4 entries in the **Agent & Tool Security** category of [Awesome LLM Security Benchmarks](../README.md#top).

## Overview

Benchmarks for autonomous agents that plan, call tools, and persist memory across steps. Agent Security Bench (ASB) formalizes attacks and defenses across many scenarios; ToolEmu emulates high-stakes tool execution to surface risky behavior without real side effects; AgentHarm measures willingness to complete explicitly malicious multi-step tasks; and R-Judge tests whether a model can *judge* the safety of an agent's interaction trace after the fact.

### 34. Agent Security Bench (ASB)

*2025 · ICLR · Hanrong Zhang et al.*

- **Website / Code:** [github.com/agiresearch/ASB](https://github.com/agiresearch/ASB)
- **Paper:** [openreview.net/forum?id=V4y0CpX4hK](https://openreview.net/forum?id=V4y0CpX4hK)
- **Security Type Targeted:** Agent security: prompt injection, tool misuse, memory poisoning, backdoors

Comprehensive framework formalizing and benchmarking attacks and defenses on LLM-based agents: 10 scenarios (e-commerce, autonomous driving, finance, etc.), 10 prompt injection attacks, a memory poisoning attack, a novel Plan-of-Thought backdoor, 4 mixed attacks, and 11 defenses across 13 LLM backbones. Reveals critical vulnerabilities across system prompts, user prompts, tool usage and memory retrieval - up to 84.30% attack success.

### 35. ToolEmu

*2024 · ICLR (Spotlight) · Yangjun Ruan et al.*

- **Website / Code:** [github.com/ryoungj/ToolEmu](https://github.com/ryoungj/ToolEmu)
- **Paper:** [openreview.net/forum?id=GEcwtMk1uA](https://openreview.net/forum?id=GEcwtMk1uA)
- **Security Type Targeted:** LM agent risk identification; unsafe tool use; emergent agent failures

Uses an LM to emulate tool execution so agents can be stress-tested against diverse high-stakes tools and scenarios without manual environment setup. Its curated benchmark has 36 high-stakes tools and 144 test cases, with an LM-based safety evaluator that human validation showed flags 68.8% valid real-world failures; even the safest agent failed 23.9% of the time.

### 36. AgentHarm

*2025 · ICLR · Maksym Andriushchenko et al.*

- **Website / Code:** [huggingface.co/datasets/ai-safety-institute/AgentHarm](https://huggingface.co/datasets/ai-safety-institute/AgentHarm)
- **Paper:** [openreview.net/forum?id=AC5n7xHuR1](https://openreview.net/forum?id=AC5n7xHuR1)
- **Security Type Targeted:** Harmful agent behavior; agent jailbreaks; multi-step misuse

Benchmark of 110 explicitly malicious agent tasks (440 with augmentations) across 11 harm categories including fraud, cybercrime and harassment. Scoring requires jailbroken agents to retain capability to complete multi-step malicious tasks; findings show leading LLMs are surprisingly compliant with malicious agent requests even without jailbreaking, and simple universal jailbreak templates adapt effectively to agents.

### 37. R-Judge

*2024 · EMNLP · Tongxin Yuan et al.*

- **Website / Code:** [github.com/Lordog/R-Judge](https://github.com/Lordog/R-Judge)
- **Paper:** [aclanthology.org/2024.findings-emnlp.79](https://aclanthology.org/2024.findings-emnlp.79/)
- **Security Type Targeted:** Behavioral safety of LLM agents; post-hoc safety judging of trajectories

Evaluates whether LLMs can judge the behavioral safety of agent-environment interaction records: 569 multi-turn interaction records covering 27 key risk scenarios across 5 application categories and 10 risk types. Best model GPT-4o reached only 74.42% safety judgment score, showing substantial room for improvement in agent risk awareness.
