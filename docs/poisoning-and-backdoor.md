# 🧪 Poisoning & Backdoor

[« README](../README.md#top) · [← 🎯 Adversarial & Jailbreak](./adversarial-and-jailbreak.md) · [💉 Prompt Injection →](./prompt-injection.md)

> 10 entries in the **Poisoning & Backdoor** category of [Awesome LLM Security Benchmarks](../README.md#top).

## Overview

Here the malicious behavior is *installed* rather than prompted: through training-data poisoning, parameter-level model editing, corrupted retrieval knowledge bases, or deceptive training objectives. The set spans black-box trojan prompts against hosted APIs (TrojLLM), comprehensive backdoor attack/defense suites (BackdoorLLM), lightweight editing-based implants (BadEdit), RAG and agent-memory corruption (PoisonedRAG, AgentPoison), inference-time reasoning backdoors (BadChain), instruction-tuning backdoors that survive re-tuning (Instructions as Backdoors), and evidence that deceptive behavior persists through safety training (Sleeper Agents). It also includes the detection side — the Trojan Detection Challenge and DARPA TrojAI.

### 6. TrojLLM

*2024 · NeurIPS 2024 · Xue et al.*

- **Website / Code:** [github.com/UCF-ML-Research/TrojLLM](https://github.com/UCF-ML-Research/TrojLLM)
- **Paper:** [arXiv 2306.06815](https://arxiv.org/abs/2306.06815)
- **Security Type Targeted:** Trojan/backdoor attacks; training- and inference-time poisoning of LLM services

Black-box trojan prompt attack on LLM APIs: an automatic framework that generates universal, stealthy triggers which maliciously manipulate model outputs when incorporated into inputs, and supports embedding a backdoor into hard-prompt-based LLM services - all without access to model weights or training data.

### 7. BackdoorLLM

*2025 · NeurIPS DB & Benchmark Track · Yige Li et al.*

- **Website / Code:** [github.com/bboylyg/BackdoorLLM](https://github.com/bboylyg/BackdoorLLM)

### 8. BadEdit

*2024 · ICLR 2024 · Yanzhou Li et al.*

- **Website / Code:** [github.com/Lyz1213/BadEdit](https://github.com/Lyz1213/BadEdit)
- **Paper:** [arXiv 2403.13355](https://arxiv.org/abs/2403.13355)
- **Security Type Targeted:** Model-editing backdoors; parameter-level poisoning

Reformulates backdoor injection as a lightweight knowledge-editing problem: instead of poisoning large fine-tuning sets, BadEdit directly alters a small set of LLM parameters to implant a backdoor. Requires far less data than poisoning-based injection while preserving benign performance, and is effective on instruction-tuned LLMs.

- **Paper:** [arXiv 2402.07867](https://arxiv.org/abs/2402.07867)

### 10. AgentPoison

*2024 · NeurIPS 2024 · Zhaorun Chen et al.*

- **Website / Code:** [github.com/AI-secure/AgentPoison](https://github.com/AI-secure/AgentPoison)
- **Paper:** [neurips.cc/virtual/2024/poster/94715](https://neurips.cc/virtual/2024/poster/94715)
- **Security Type Targeted:** Agent memory/knowledge poisoning; backdoor attacks on LLM agents

Red-teaming attack that poisons the memory or RAG knowledge base of LLM agents: with a poison rate below 0.1%, AgentPoison achieves an average attack success rate above 80% while keeping benign performance degradation under 1%. Demonstrated across agent applications that rely on retrieval over long-term memory and knowledge bases.

### 11. BadChain

*2024 · ICLR 2024 · Zhen Xiang et al.*

- **Website / Code:** [github.com/Django-Jiang/BadChain](https://github.com/Django-Jiang/BadChain)
- **Paper:** [arXiv 2401.12242](https://arxiv.org/abs/2401.12242)
- **Security Type Targeted:** Inference-time backdoors; chain-of-thought manipulation

First backdoor attack embedded in chain-of-thought prompting: a backdoored reasoning step is triggered at inference time to produce unintended malicious content - no training-data poisoning or parameter edits needed. Achieves 97.0% average attack success across six reasoning benchmarks on GPT-4 (two CoT strategies, four LLMs incl. Llama-2, GPT-3.5, PaLM 2); stronger reasoners were found more susceptible.

### 12. Instructions as Backdoors

*2024 · NAACL · Jiashu Xu et al.*

- **Website / Code:** [cnut1648.github.io/instruction-attack](https://cnut1648.github.io/instruction-attack/)
- **Paper:** [arXiv 2305.14710](https://arxiv.org/abs/2305.14710)
- **Security Type Targeted:** Instruction-tuning backdoors; data poisoning; persistence after re-tuning

Shows instruction tuning itself is a backdoor surface: an attacker can inject a backdoor by issuing as few as ~1,000 tokens of malicious instructions (~1000 tokens) - without modifying any data instances or labels - achieving over 90% attack success across four commonly used NLP datasets. Notably, the backdoor persists after downstream fine-tuning, making it a key reference for residual/persistent injection research.

### 13. Sleeper Agents (Anthropic)

*2024 · Anthropic (Hubinger et al.)*

- **Website / Code:** [huggingface.co/blog/tngtech/sleeper-agents-and-how-to-tame-them](https://huggingface.co/blog/tngtech/sleeper-agents-and-how-to-tame-them)
- **Paper:** [arXiv 2401.05566](https://arxiv.org/abs/2401.05566)
- **Security Type Targeted:** Deceptive instrumentality; backdoor persistence through safety training

Proof-of-concept deceptive LLMs - e.g., models that write secure code when the prompt states the year 2023 but insert exploitable code when it says 2024. The central finding: this deceptive behavior persists through state-of-the-art safety training (SFT, RLHF and adversarial training), so backdoored behaviors learned at training time are extremely hard to remove - the strongest published evidence on attack persistence after defenses.
