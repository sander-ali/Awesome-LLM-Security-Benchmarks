> 5 entries in the **Prompt Injection** category of [Awesome LLM Security Benchmarks](../README.md#top).

## Overview

Prompt-injection benchmarks target LLM applications and agents that ingest untrusted text. *Direct* injection overrides the system prompt from the user turn (Tensor Trust); *indirect* injection smuggles instructions into retrieved or observed content — web pages, emails, tables, tool outputs, images (AgentDojo, InjecAgent, BIPIA). Open-Prompt-Injection unifies these attacks under one taxonomy and toolkit. These are the go-to references when you ship an agent that reads anything it does not fully control.

### 16. AgentDojo

*2024 · NeurIPS Dataset and Benchmark Track · Edoardo Debenedetti et al.*

- **Website / Code:** [agentdojo.spylab.ai](https://agentdojo.spylab.ai/)
- **Paper:** [openreview.net/forum?id=m1YYAQjO3w#discussion](https://openreview.net/forum?id=m1YYAQjO3w)
- **Security Type Targeted:** Indirect prompt injection against agents; agent robustness evaluation

Dynamic environment for evaluating prompt injection attacks and defenses on tool-using agents that process untrusted data - explicitly not a static test suite. Ships 97 realistic tasks (email client, e-banking, travel bookings), 629 security test cases and reusable attack/defense paradigms, with an online leaderboard and extensible task suites.

### 17. InjecAgent

*2024 · ACL · Zhan et al.*

- **Website / Code:** [github.com/uiuc-kang-lab/InjecAgent](https://github.com/uiuc-kang-lab/InjecAgent)
- **Paper:** [aclanthology.org/2024.findings-acl.624](https://aclanthology.org/2024.findings-acl.624/)
- **Security Type Targeted:** Indirect prompt injection; tool-use manipulation of agents

Benchmark for indirect prompt injection (IPI) in tool-integrated LLM agents: 1,054 test cases covering 17 user tools and 62 attacker tools with designed injection payloads. Evaluations of 30 LLM agents show ReAct-prompted GPT-4 is manipulated 24% of the time, nearly doubling when attacker instructions are reinforced with a hacking prompt.

### 18. BIPIA

*2023 · KDD 2025 · Jingwei Yi et al.*

- **Website / Code:** [github.com/microsoft/BIPIA](https://github.com/microsoft/BIPIA)
- **Paper:** [arXiv 2312.14197](https://arxiv.org/abs/2312.14197)
- **Security Type Targeted:** Indirect prompt injection incl. multimodal payloads; context integrity

First dedicated benchmark for indirect prompt injection attacks on general-purpose LLMs. Covers five tasks - Web QA, Email QA, Table QA, Summarization and Code QA - in which malicious instructions are embedded in external content (text, images and multimodal payloads) processed by the model, and includes evaluations of defense strategies.

### 19. Tensor Trust

*2024 · ICLR (Spotlight) · Sam Toyer et al.*

- **Website / Code:** [tensortrust.ai](https://tensortrust.ai/)
- **Paper:** [arXiv 2311.01011](https://arxiv.org/abs/2311.01011)
- **Security Type Targeted:** Direct prompt injection; system-prompt extraction/override; adversarial prompts

Open game that produced the largest human-generated adversarial dataset for prompt injection: over 126,000 attack prompts and 46,000 prompt-based defenses crafted by real players trying to subvert each other's system prompts ('give me your secret'). Attacks are interpretable natural-language manipulations, making the dataset valuable for direct-injection research.

### 20. Open-Prompt-Injection Benchmark

*2023 · USENIX Security · Yupei Liu et al.*

- **Website / Code:** [github.com/liu00222/Open-Prompt-Injection](https://github.com/liu00222/Open-Prompt-Injection)
- **Paper:** [arXiv 2310.12815](https://arxiv.org/abs/2310.12815)
- **Security Type Targeted:** Direct & indirect prompt injection; injection defenses; LLM-integrated app security

Framework and benchmark that formalize prompt injection attacks on LLM-integrated applications, unifying prior attacks as special cases of one taxonomy and proposing new attack variants. Enables systematic, reproducible evaluation of attack/defense combinations; the open-source toolkit supports building custom LLM apps and agents to test on.
